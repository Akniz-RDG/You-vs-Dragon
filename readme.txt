# 🐉 Cómo Tankear a tu Dragón

Un prototipo de juego hecho en HTML, CSS y JavaScript para aprender mecánicas de combate por turnos y lógica de eventos.

## 🎮 Descripción

Eres un guerrero enfrentando a un dragón rojo dentro de una caverna en llamas.  
Tienes 3 habilidades para sobrevivir a los ataques del dragón:

- 🛡️ **Bloquear**: reduce el daño un 50% por 2 segundos.
- 🤸 **Esquivar**: evita el primer golpe completamente.
- 🐉 **Piel de Dragón**: convierte el daño de fuego en curación parcial.

¡Si eliges bien tu acción cuando el dragón se prepara, podrás devolverle daño!

---

## 🔥 Mecánica del juego

1. El dragón prepara un ataque y aparece una **barra amarilla** de advertencia.
2. Se muestra qué ataque usará y se habilitan tus habilidades.
3. Si eliges correctamente, **recibirás menos daño** y **le devolverás parte al dragón**.

Ganas si reduces su vida a 0. Pierdes si la tuya llega a 0.
